# 🏏 IPL 2022 Analysis & Data Visualization

A capstone analysis of the **IPL 2022** season plus a set of visualization notebooks covering the main Python plotting libraries.

## IPL 2022 capstone — `ipl_capstone_project.ipynb`
Questions explored using `IPL.csv` (every match of the season):
- Which team won the most matches?
- Toss decision trends — bat or field first?

## Visualization notebooks
| Notebook | Covers |
|---|---|
| `Matplotlib.ipynb` | Line, bar, scatter, subplots, styling |
| `Distribution.ipynb` | Histograms, KDE, joint & pair plots |
| `Categorical.ipynb` | Bar, count, box, violin, swarm plots |
| `Matrixplot.ipynb` | Heatmaps and clustermaps |
| `Regression.ipynb` | `lmplot` / regression plots |
| `plotlyandcufflinks.ipynb` | Interactive charts with Plotly & Cufflinks |

## Tech stack
Python · pandas · Matplotlib · Seaborn · Plotly
